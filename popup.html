Data details and current settings

Crossref receives DOIs. NCBI receives DOI, PMID or PMCID identifiers. Page text, search queries and page addresses are not sent.

Checks run automatically when a page exposes article or reference identifiers. Enable or disable either service in Quick settings, then select Save quick settings.
