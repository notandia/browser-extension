# Notandia 0.1.0 release notes

Notandia broadens the original publisher-context extension into an explainable scholarly-context tool.

## Highlights

- configurable publisher watchlist profiles, including MDPI and Frontiers;
- formal post-publication context through Crossref and Retraction Watch data;
- DOI, PMID, PMCID, and arXiv identifier normalization through the shared work-identity layer;
- governed optional NCBI metadata resolution with provider-required client identification and serialized requests;
- source-level Google Search handling for ordinary results, AI Overview sources, and People Also Ask content;
- shared Google/Google Scholar work identity so publisher context and formal-integrity checks use the same DOI/PMID/PMCID resolution path;
- exact-title convergence for alternate representations of the same work when the page provides one unambiguous resolved DOI;
- status-looking title labels are not trusted as formal evidence; retraction/correction status still requires the configured formal provider;
- improved bibliography-to-inline-citation mapping across structured publishing platforms;
- hidden/collapsed bibliography disclosure before navigation and pulse animation;
- Notandia-branded popup, settings, runtime namespaces, icons, and browser packages.

## Google composite modules

Notandia does not classify an AI Overview or People Also Ask container as a publication. It evaluates the individual scholarly source/result units inside those modules. Dynamically inserted sources are rescanned after expansion.

## Compatibility

Some released storage keys, runtime aliases, and DOM compatibility attributes remain temporarily available so existing browser installations can update without losing settings or breaking mature citation/navigation paths. New general-purpose code uses the Notandia namespace.
