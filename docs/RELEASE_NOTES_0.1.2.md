# Notandia 0.1.2

- Expand optional publisher and journal warnings with local Cite Unseen URL lists and Wikipedia CiteWatch identifiers, assessment notes and source links.
- Improve reference detection and popup counts, with clearer scan coverage and recovery controls.
- Add a first-use setup for Crossref and NCBI checks. Each service remains optional, and updates preserve saved choices independently.
- Extend MDPI and Frontiers DOI coverage and distinguish preprints and Encyclopedia entries.
- Keep distinct publisher colours, accessible controls, manual publisher rules and profile import/export. Remove the repeated category label beside MDPI and Frontiers.

Warnings identify watchlist or source-list matches; they are not an article quality score. CiteWatch name/prefix matches are potential and respect scope exceptions. Crossref supplies formal update metadata, including Retraction Watch information where available. NCBI supplies identifier metadata. Bundled Wikimedia adaptations include dated revisions and CC BY-SA attribution.

Chrome and Edge packages update their existing store products. Firefox and Safari source packages are included; installation through their stores requires signing and review. Store review status is separate from the GitHub release.
